# playbook

Ryan's own skills, designed to sit alongside Superpowers rather than replace any of it:

- `/playbook:init-project` sets up or audits a project: a lean CLAUDE.md, path-scoped rules files, and shared permission guardrails.
- `/playbook:lesson` turns a mistake or correction into a lesson in the right place: the project's `CLAUDE.md`, an area rules file, or a new rule in the playbook.

Install:

```
/plugin install playbook --marketplace rydncn/ai-playbook
```

See the repository's `README.md`, `VERIFICATION.md` and `rules/` for the reasoning behind them.
